## About me

I'm Dang Chi Son, a software engineer based in Da Nang, Vietnam. My work focuses on frontend architecture, complex web applications, and technical leadership, primarily with TypeScript, Vue.js, React, and Angular.

I spent nearly a decade at NeoLab and DGWAsian, working on product development and leading frontend teams. My responsibilities included architecture proposals, code reviews, mentoring, performance investigations, and hands-on implementation.

I also build full-stack applications and open-source developer tools. My current interests include AI agent integrations, the Model Context Protocol (MCP), and automation that addresses practical needs in my own workflow.
